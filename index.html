OpenPERouter #

OpenPERouter is an open-source Provider Edge (PE) router for Kubernetes. It runs on Kubernetes nodes, terminates VPN protocols, and exposes a BGP interface to the host network—so BGP-speaking components can integrate as if they were connected to a physical PE router.

It supports Layer 2 and Layer 3 overlays, including EVPN/VXLAN and SRv6 L3VPN.

OpenPERouter is under active development. Use it carefully.
